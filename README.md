# data-analysis-scripts

Collection of data analysis scripts used in published research projects.

## Contents

- Conditional Accuracy Function (CAF) analysis
- Delta plot analysis for response time distributions

## Technologies

- R

## Description

These scripts include data preprocessing, statistical analysis, and reproducible workflows used in experimental research.

## Structure

Each study is organized in separate folders, including preprocessing and analysis scripts.

## Publications

- Exploring the spatial interference effects elicited by social and non-social targets: A conditional accuracy function approach (https://doi.org/10.1111/bjop.12735)
- Investigating the gaze-driven reversed congruency effect in the spatial Stroop task: A distributional approach (https://doi.org/10.1111/bjop.70004)
